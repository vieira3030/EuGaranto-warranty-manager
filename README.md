# EuGaranto

A warranty management app built with Ionic and Angular, using Firebase as backend. Started as a UX research and prototyping project (user interviews, low-fidelity Figma prototypes) and evolved into a working implementation.

## Features
- User authentication (login/signup)
- Warranty registration and management
- Firebase-backed data storage

## Tech Stack
Ionic · Angular · Firebase · Capacitor

## Design Process
Before implementation, the project went through a full UX research cycle:
- User research questionnaire and task analysis
- Conceptual model definition
- Low-fidelity prototypes in Figma
- Storyboards and interaction scenarios

## How to Run
```bash
git clone https://github.com/vieira3030/eugaranto.git
cd eugaranto
npm install
ionic serve
```
